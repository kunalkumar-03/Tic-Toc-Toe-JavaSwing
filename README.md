# 🎮 TicTacToe-JavaSwing

A simple and fun Tic-Tac-Toe game built using Java Swing and AWT.  
This project was created for learning and practicing Java GUI development.

---

## 📌 Features

- ✅ 2 Player Tic-Tac-Toe
- ✅ Interactive GUI using Java Swing
- ✅ Winner detection
- ✅ Draw detection
- ✅ Color highlights for winners
- ✅ Simple and clean interface

---

## 🛠️ Technologies Used

- Java
- Swing
- AWT

---

## 🎯 Game Rules

- Player **X** starts first.
- Players take turns placing X and O.
- The first player to align:
  - 3 rows
  - 3 columns
  - or diagonal
  wins the game.
- If all boxes are filled and nobody wins, the game ends in a draw.
